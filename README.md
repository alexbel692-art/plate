# PlateReader

Распознавание автомобильных номеров с IP-камеры (HiWatch/Hikvision и любые RTSP) и журнал проездов в Excel.

- видео с камеры с подсветкой найденных номеров;
- таблица проездов со снимками, журнал `Документы\Проезды\проезды.xlsx`;
- настройки камеры и распознавания в программе, выделение области въезда мышью;
- работа в фоне со значком у часов, автозапуск с Windows;
- модели распознавания встроены в установщик, интернет не нужен.

## Установка
Скачайте `PlateReader-Setup-*.exe` из раздела **Releases** и запустите.
Права администратора не нужны. Настройки старой версии (скрипта) переносятся сами.

## Сборка
Установщик собирает GitHub Actions на Windows при каждом push в `main`
(`.github/workflows/build.yml`): PyInstaller + Inno Setup.
